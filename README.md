## 🌎 About the Project

Gigio's Aquarium is an educational simulation designed to demonstrate fundamental concepts behind NPC (Non-Player Character) intelligence through autonomous fish agents living in a virtual aquarium.

Inspired by the behavioral systems found in games such as Grand Theft Auto, this project transforms abstract concepts of artificial intelligence into observable and interactive experiences.

Instead of simply explaining how an NPC works, students can watch its behavior, inspect its internal state, change environmental conditions, and observe how different rules produce different actions.

**This is a rule-based simulation. It does not use a Large Language Model (LLM), nor does it imply consciousness or human-like understanding in its agents.**

## 🧠 The NPC Decision Cycle

The simulation explores six fundamental stages of an autonomous agent's decision-making process:

| Stage | Description |
|---|---|
| 1. Perception | The agent senses its environment and internal conditions. |
| 2. Working Memory | Relevant information is temporarily maintained for decision-making. |
| 3. Processing | The agent evaluates available information and behavioral rules. |
| 4. Trigger | A condition or event enables a possible response. |
| 5. Action Plan | The agent determines what action should be performed. |
| 6. Execution | The action is carried out, changing the agent or its environment. |

The cycle then repeats:

**Perception → Working Memory → Processing → Trigger → Action Plan → Execution → New Perception**

An important distinction: a trigger is not the action itself. It is a condition that makes a response possible. The action plan determines what should happen next.

## 🐠 Autonomous Agents

Each fish can have different characteristics and behavioral tendencies.

### Species

Species represent the biological identity of each agent.

### Schools

A school is a dynamic social and spatial grouping of two or more fish of the same species swimming together.

School membership is not permanent. Fish can join or leave a school without changing their species or behavioral profile.

### Behavioral Profiles

The simulation uses three behavioral profiles:

- **A — Cooperative**
- **B — Explorer**
- **C — Competitive**

These profiles influence how agents respond to their environment and interact with other agents.

Species, school membership, and behavioral profile are separate concepts.

## 🌱 Interactions and Emergent Behavior

The aquarium allows the observation of different interactions and environmental situations, including:

- Food detection and consumption.
- Communication through environmental announcements.
- Predator detection and escape behavior.
- Predatory behavior and hunting.
- Reproduction and birth.
- Protection of young fish.
- Social grouping and school detection.
- Changes in behavior according to internal conditions.
- Competition and cooperation between agents.

The purpose is to observe how individual rules and interactions can produce collective and sometimes unexpected behavior.

## 🎓 Educational Purpose

Gigio's Aquarium was developed as a teaching resource to make concepts related to programming, artificial intelligence, autonomous agents, and game development easier to understand.

It can be used to explore questions such as:

- How does an NPC know what is happening around it?
- What information does an agent need to remember?
- How does a game character decide what to do?
- What happens when two behavioral rules compete?
- How can simple rules generate complex behavior?
- Why can an agent change its plans when the environment changes?

The aquarium turns these questions into experiments that can be observed and discussed.

## 🧠 O Ciclo de Decisão de um NPC

A simulação explora seis etapas fundamentais do processo de decisão de um agente autônomo:

| Etapa | Descrição |
|---|---|
| 1. Percepção | O agente identifica informações do ambiente e de suas próprias condições internas. |
| 2. Memória de Trabalho | Informações relevantes são mantidas temporariamente para apoiar a tomada de decisão. |
| 3. Processamento | O agente avalia as informações disponíveis e suas regras comportamentais. |
| 4. Gatilho | Uma condição ou acontecimento habilita uma possível resposta. |
| 5. Plano de Ação | O agente define qual ação deverá ser realizada. |
| 6. Execução | A ação é realizada, modificando o agente ou o ambiente. |

O ciclo se repete continuamente:

**Percepção → Memória de Trabalho → Processamento → Gatilho → Plano de Ação → Execução → Nova Percepção**

Uma distinção importante: o gatilho não é a ação. Ele representa uma condição que possibilita uma resposta. O plano de ação determina o que deverá acontecer em seguida.

## 🐠 Agentes Autônomos

Cada peixe possui características e tendências comportamentais próprias.

### Espécies

Representam a identidade biológica de cada agente.

### Cardumes

Um cardume é um agrupamento social e espacial dinâmico de dois ou mais peixes da mesma espécie que nadam juntos.

A participação em um cardume não é permanente. Os peixes podem entrar ou sair de um agrupamento sem alterar sua espécie ou seu perfil comportamental.

### Perfis Comportamentais

A simulação trabalha com três perfis:

- **A — Cooperativo**
- **B — Explorador**
- **C — Competitivo**

Esses perfis influenciam a maneira como os agentes respondem ao ambiente e interagem com outros agentes.

Espécie, participação em cardume e perfil comportamental são conceitos distintos.
